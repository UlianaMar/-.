# 1. Описание системы
Название: Wildberries
Ссылка: https://wildberries.ru/
Назначение:
Wildberries — крупный международный маркетплейс, предназначенный для онлайн-
продажи товаров широкого спектра: от одежды и обуви до электроники и товаров для
дома.
Целевая аудитория:
 Покупатели (физические лица), ищущие товары повседневного спроса.
 Продавцы и владельцы бизнеса, реализующие товары через платформу.
Основные возможности:
 Поиск и фильтрация товаров по категориям, цене, рейтингу и характеристикам.
 Просмотр карточек товаров с фото, отзывами и описанием.
 Добавление товаров в корзину и оформление заказа.
 Личный кабинет покупателя и панель продавца.
 Отслеживание статуса доставки.
Выбранный сценарий:
Поиск товара и просмотр карточки товара.

# 3.6. Запрос при поиске товара
При вводе запроса в поисковую строку отправляется сетевой запрос.
Основные параметры:
 Метод: GET
 URL: /search?query=...
 Статус: 200 OK
 Данные: JSON с массивом найденных товаров.
# 3.7. Вывод
Клиентская часть Wildberries отвечает за динамическое отображение данных. JavaScript
обрабатывает действия пользователя (ввод запроса, клики), отправляет асинхронные
запросы к API и обновляет DOM-дерево без полной перезагрузки страницы, обеспечивая
высокую скорость работы.
# 4. Анализ серверной части и API
# 4.1. Серверная часть
Серверная часть Wildberries отвечает за обработку поисковых запросов, формирование
выдачи, работу с базой данных товаров и пользователей, а также за обработку заказов.
# 4.2. Передаваемые данные
При поиске и просмотре карточки между клиентом и сервером передаются:
 Поисковый запрос.
 Идентификатор товара.
 Данные о товаре (цена, наличие, описание).
 Информация о пользователе (для корзины).
# 4.3. API и сетевое взаимодействие
В разделе Network были обнаружены запросы к API.
Пример запроса:
 Метод: GET
 URL: /api/v1/search
 Тип: Fetch/XHR
 Назначение: Получение списка товаров по запросу.
API позволяет клиентской части получать данные в формате JSON для дальнейшего
отображения.

# 5. Описание пользовательского сценария
# 5.1. Выбранный сценарий
Название сценария: Поиск товара и просмотр карточки товара на Wildberries.
Цель сценария: Найти нужный товар и получить подробную информацию о нем.
# 5.2. Последовательность выполнения сценария
Этап 1. Пользователь открывает сайт.
Пользователь заходит на wildberries.ru. Браузер загружает HTML, CSS и JavaScript.
Этап 2. Ввод поискового запроса.
Пользователь вводит запрос в строку поиска и нажимает кнопку «Найти».
Этап 3. Формирование запроса.
Клиентская часть отправляет GET-запрос на сервер с поисковым запросом.
Этап 4. Обработка на сервере.
Сервер ищет товары в базе данных, соответствующие запросу, и возвращает результат.
Этап 5. Отображение результатов.
Клиент получает JSON с товарами и отображает их в виде списка карточек.
Этап 6. Переход к товару.
Пользователь кликает на карточку товара. Клиент запрашивает детальную информацию о
товаре.
Этап 7. Просмотр карточки.
Интерфейс отображает полную информацию о товаре (фото, цена, описание, отзывы).
Пользователь изучает данные.

# 6. Построение архитектурной схемы
# 6.1. Архитектурная схема
Для демонстрационного варианта была построена упрощенная архитектурная схема
Wildberries.
На схеме представлены основные компоненты:
 Пользователь.
 Браузер.
 Клиентская часть.
 API Gateway.
 Серверная часть (микросервисы поиска и каталога).
 Хранилище данных.
# 6.2. Взаимодействие компонентов
Основные взаимодействия в системе:
1. Пользователь выполняет действия в браузере.
2. Браузер обрабатывает интерфейс и выполняет JavaScript-код.
3. Клиентская часть отправляет запросы через API.
4. API Gateway маршрутизирует запросы к соответствующим микросервисам.
5. Микросервисы обращаются к базе данных.
6. Сервер возвращает результат клиентской части.
7. Интерфейс обновляется.
