# 1. Описание системы
Название: Wildberries
Ссылка: https://wildberries.ru/
Назначение:
Wildberries — крупный международный маркетплейс, предназначенный для онлайн-
продажи товаров широкого спектра: от одежды и обуви до электроники и товаров для
дома.
Целевая аудитория:
 Покупатели (физические лица), ищущие товары повседневного спроса.
 Продавцы и владельцы бизнеса, реализующие товары через платформу.
Основные возможности:
 Поиск и фильтрация товаров по категориям, цене, рейтингу и характеристикам.
 Просмотр карточек товаров с фото, отзывами и описанием.
 Добавление товаров в корзину и оформление заказа.
 Личный кабинет покупателя и панель продавца.
 Отслеживание статуса доставки.
Выбранный сценарий:
Поиск товара и просмотр карточки товара.
# 2. Анализ пользовательского интерфейса
# 2.1. Основные страницы и разделы
В системе используются следующие основные страницы:
 Главная страница.
 Страница результатов поиска (каталог).
 Карточка товара.
 Корзина.
 Личный кабинет.

# 2.3. Выполнение пользовательского сценария
Последовательность действий для сценария «Поиск товара и просмотр карточки»:
1. Открыть сайт Wildberries.
2. Ввести название товара (например, "беспроводные наушники") в строку поиска и
нажать "Найти".
3. Ознакомиться с выдачей и выбрать подходящий товар.
4. Кликнуть на карточку товара для перехода на страницу товара.
5. Изучить подробную информацию (описание, характеристики, фото, отзывы).
6. Оценить результат.
